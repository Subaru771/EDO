EDO — SHARE PC TO PC, PHONE TO PC, OR WITH GOOGLE TV

1. Extract this ZIP. On GitHub.com, create an empty repository and select Add file > Upload files.
2. Drag the CONTENTS of the Edo-GitHub-Upload folder (not the ZIP itself) onto GitHub.
3. Commit changes. README.md is your public guide; it starts with PC-to-PC (NO TV NEEDED).
4. For Windows PC-to-PC sharing, run desktop/dist/Edo-Windows.vbs on PC A (Java 17+), start sharing, then open the shown address in PC B's browser and pair.
5. For Google TV, use Actions to build the APK; test before publishing any release asset.

Files are LAN-only by default. Plain HTTP is not encrypted. Do not publish signing keys or passwords.
Full iOS source and additional website files are in the full publishing project ZIP.
