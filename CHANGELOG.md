# Changelog

## Unreleased — Edo UI overhaul preview

- Windows: mint-and-midnight workspace, resizable navigation, refreshed sharing dashboard,
  connection cards, controls and file explorer.
- Android TV: higher-contrast, remote-first connection page with QR/PIN pairing,
  grouped file actions, expandable security tools, and refreshed secondary screens.
- Browser: desktop workspace sidebar, mobile navigation, accessible current-tab state,
  refined upload queue, file browser, pairing screen, and adaptable light/dark themes.
- Transfer protocol, pairing API and file operations remain unchanged.
- Preview binaries are generated by the UI-overhaul workflow; **do not use these
  unsigned/debug artifacts as upgrades for the signed Android v1.0 release**.
- Stable v1.0 public release remains unchanged until build validation and device testing.

## Edo v1.0 — First unified public release

- Public v1.0 identity across Google TV / Android TV and Windows Desktop.
- Native Android TV sharing host with browser-only PC/phone clients.
- Redesigned Windows dashboard: Share, Your files, Backup & Sync, Settings.
- Desktop shared-folder browser and safe file-management actions.
- Local pairing and host approvals; optional HTTPS and WebDAV.
- Android package ID retained, Android version code increased to **57** for upgrades.
- Portable Windows executable with bundled Java.
- Documentation and repository cleanup, tests and CI.
- Signed Android v1.0 APK and Windows portable package validated on the user's devices prior to publication.

Older development history remains in Git commits. The [legacy release](https://github.com/Subaru771/EDO/releases/tag/v5.4.2) is available separately.
