# Edo Desktop v1.0

**Windows desktop host** for local PC/phone sharing.

- **Java ZIP:** extract and run `Start-Edo-Windows.vbs` with Java 21+ installed.
- **Windows portable:** [GitHub Actions](https://github.com/Subaru771/EDO/actions/workflows/desktop-windows.yml) also builds `Edo.exe` with a bundled Java runtime.
- **Share files:** select a shared folder, click Start sharing, then enter the displayed URL in the second device's browser.
- **Your files:** search, import, open, rename, copy, move and delete files within the shared folder.
- **Settings:** PIN pairing, optional host approval and HTTPS.

See [Windows setup](../docs/WINDOWS-SETUP.md) and [PC-to-PC guide](../docs/PC-TO-PC.md). Downloads: [Edo Releases](https://github.com/Subaru771/EDO/releases).

Requires Java 21+ for JAR operation. Transfer HTTP is unencrypted.
