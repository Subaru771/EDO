# Edo — Every Device. One Connection.

**Free local file sharing. A TV is optional.**

### What can I connect?
- **PC ↔ PC:** Run Edo Desktop on PC A; open its local address in a browser on PC B. Upload to PC A or download from PC A. **No TV needed.**
- **PC / phone ↔ Google TV:** Install Edo on the TV, scan its QR code or use its local address, pair using the displayed PIN, and transfer.
- **Phone ↔ PC:** Run Edo Desktop on the PC and connect from your phone browser.

### Get started
1. Download the appropriate **verified** asset for your host device (TV APK or desktop companion), once the release has passed device testing.
2. Start Edo and choose a folder to share (desktop) or view the TV's QR code.
3. On the other device, open the local address and pair using the PIN.
4. Use **Transfer** to upload to the host, and **Files** to download from it.

More: [PC-to-PC walkthrough](docs/PC-TO-PC.md) | [Full sharing guide](docs/SHARING-GUIDE.md)

**Security:** Local HTTP traffic is unencrypted; use only on trusted LANs. Optional HTTPS uses a local certificate requiring verification/trust. Do not port-forward Edo. The Android APK has not yet been verified on a physical TV in the authoring environment.
