# Edo 1.0 — Sharing clarity update

**No changes to file transfer protocols or classic Google TV screen layout.** This release makes PC-to-PC and phone-to-PC transfers much easier to discover.

- Reorganized GitHub README around supported sharing scenarios, with PC-to-PC at the top.
- Added an explicit PC-to-PC guide and all-devices sharing matrix.
- Added a “How to transfer between devices” Help button inside Edo Desktop.
- Updated desktop labels to clarify that the remote Edo host may be another PC, not just a TV.
- Added a collapsible sharing guide in the paired device browser UI.
- Updated public website and release text to say **PC to PC requires no television**.
- Increased Android versionCode to 56 / versionName to 5.4.2, so Android upgrades are clearly identified.

The Android APK is still not built or verified on a physical TV in this environment. Desktop JAR is rebuilt, and the Java regression tests pass.
