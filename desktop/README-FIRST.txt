EDO DESKTOP v1.0 — WINDOWS

What's included
- Modern dark desktop dashboard
- Native Your files browser: search, import, create folders, open, rename, copy/move and delete
- Local file sharing from a PC to other PCs and phones
- Backup and Sync, pairing and security settings

How to start
1. Extract the ZIP completely.
2. Install Java 21+: https://adoptium.net/temurin/releases/?version=21
3. Double-click Start-Edo-Windows.vbs; use .cmd if it does not open.
4. Choose a shared folder under Share files and press Start sharing.
5. Open Your files to manage the shared folder locally.
6. On your other PC or phone, open Edo's network address and pair.

Use trusted networks; deletion is permanent.
Android TV stays on its existing separate version.
